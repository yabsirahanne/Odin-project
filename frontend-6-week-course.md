# Frontend Fundamentals Sprint
### A 6-Week Zero-to-Portfolio Custom Course

---

## 1. Baseline Assessment (from your interview)

| Signal | Your Answer | What It Means |
|---|---|---|
| HTML/CSS | Tried, no JS | You can read markup but haven't built with structure/intent yet |
| Programming (any language) | Zero experience | **This is your real starting line** — logic, not syntax, is the mountain |
| Weekly time | 5–10 hrs/week | ~40–50 total hours over 6 weeks — enough for solid fundamentals + 1 project, not more |
| Terminal | Comfortable (cd, ls, mkdir) | Genuine asset — most true beginners struggle here, you won't |
| Learning style | Video + reading + building | Best possible combo for retention — we'll use all three every week |
| Career goal | First junior dev job ASAP | Ambitious for 6 weeks from zero — real timelines for "job ready" run 4–8 months. This course is **Phase 1**, not the finish line |
| Final project | "You decide — most impressive" | I've picked a project that hits every box recruiters and portfolios need (see below) |

**Assessed Level: True Beginner (Level 0)** in programming logic, **Level 1** (some exposure) in markup/styling.

---

## 2. The Destination

By the end of Week 6, you will be able to:

- Write semantic, structured HTML5 from a blank file — no tutorials open
- Build responsive layouts confidently using **Flexbox** and **CSS Grid**
- Write core JavaScript: variables, functions, conditionals, loops, arrays, objects
- Manipulate the DOM and respond to user events (clicks, input, etc.)
- Fetch live data from a public API and render it dynamically on a page
- Use Git/GitHub to version and deploy your work
- **Have one polished, live, deployed project** you can put on your resume and LinkedIn *today*

**Final project (decided for you):** A responsive personal portfolio site with one embedded interactive JavaScript feature — a live weather widget (or similar API-driven component) plus a dark/light mode toggle. This single project demonstrates HTML structure, CSS responsive design, JS logic, DOM manipulation, API integration, and deployment — everything a recruiter scans for in 30 seconds.

**What this course will NOT make you:** interview-ready for junior roles. That requires deeper JS, one framework (usually React), and 2–3 more solid projects. Week 6 includes your "what's next" roadmap.

---

## 3. The Sequence

| Week | Focus | Why this order |
|---|---|---|
| 1 | HTML fundamentals + Git/GitHub setup | Structure before style before logic. Git from day one avoids relearning habits later. |
| 2 | CSS fundamentals — box model, Flexbox | You style what you already know how to structure. |
| 3 | CSS Grid + responsive design | Layer complexity: Grid builds on Flexbox intuition. |
| 4 | JavaScript fundamentals — logic building blocks | This is your steepest climb (zero prior experience) — it gets a full dedicated week before touching the DOM. |
| 5 | DOM manipulation + events + Fetch API | Logic is useless until it can touch a real page — this week makes JS "do something visible." |
| 6 | Integration, polish, deployment | Combine everything into the final shippable project. |

---

## 4. What to Ignore For Now

Deliberately **excluded** — these will slow you down or aren't needed for the destination above:

- React, Vue, Angular, or any framework
- TypeScript
- Sass/Less, Tailwind, or any CSS preprocessor/framework
- Build tools — Webpack, Vite, npm bundling (use plain files + Live Server)
- Backend, Node.js, databases, APIs you build yourself
- Testing frameworks (Jest, etc.)
- Advanced JS — closures, classes, prototypes, async/await beyond basic fetch
- Algorithms & data structures / LeetCode-style practice
- CSS animations beyond simple transitions
- Building multiple projects — one polished piece beats five half-finished ones

---

## 5. Weekly Milestones

**Week 1 — Structure & Setup**
- Learn HTML5 semantics (header, nav, main, section, footer) + basic Git/GitHub workflow
- 🎯 Milestone: An unstyled, multi-section HTML page (About / Projects / Contact skeleton) pushed to GitHub and live via GitHub Pages

**Week 2 — Box Model & Flexbox**
- Learn box model, positioning, Flexbox for layout and navigation
- 🎯 Milestone: Same page now styled — working nav bar, spacing, basic visual hierarchy

**Week 3 — Grid & Responsive Design**
- Learn CSS Grid, media queries, mobile-first design
- 🎯 Milestone: Fully responsive portfolio skeleton — looks correct on phone, tablet, and desktop

**Week 4 — JavaScript Logic**
- Learn variables, functions, conditionals, loops, arrays, objects — via small drills, not the portfolio yet
- 🎯 Milestone: 8–10 completed logic exercises (e.g. FizzBuzz, array filtering, a simple calculator function) in a separate practice file

**Week 5 — DOM, Events & Fetch**
- Learn `querySelector`, event listeners, and `fetch()` to call a public API
- 🎯 Milestone: A working interactive component (dark/light toggle + live weather widget) running standalone

**Week 6 — Integration & Launch**
- Merge the JS component into your portfolio site, polish CSS, write a README, deploy final version
- 🎯 Milestone: Live, deployed portfolio site + GitHub repo with clean commit history + a short "what I built and learned" writeup — ready to link on your resume and LinkedIn

---

## After Week 6: Your Real Path to "Junior Job Ready"

This course builds your foundation. To actually get interview-ready, the typical next phase (roughly 3–5 more months at your pace) is:
1. Deepen JavaScript (closures, async/await, array methods like map/filter/reduce)
2. Learn one framework — React is the most in-demand
3. Build 2–3 more projects (ideally one full-stack, even a simple one)
4. Start applying while continuing to build — most junior hires happen mid-learning, not after "finishing"

You don't need to decide any of that now — just know it's there when Week 6 ends.
